# Day 9 — Reasoning Patterns

## 1. Chain-of-Thought (CoT)
- Step by step reasoning show કરો
- Accuracy વધે — especially math + logic
- Prompt: "Think step by step"

## 2. Few-Shot CoT
- Examples આપો → AI same pattern follow કરે
- 2-3 examples = Enough
- Best for: Structured outputs

## 3. ReAct Pattern
- Reason → Act → Observe → Repeat
- Agent ની backbone
- Format:
  THOUGHT: what I think
  ACTION: what I do
  OBSERVATION: what I see
  ANSWER: final result

## 4. Self-Reflection
- AI ખુદ answer review કરે
- Critique → Improve → Better answer
- Use for: Important + Complex tasks

## Key Insights
CoT = Better reasoning
ReAct = Better actions  
Self-Reflection = Better quality
All 3 = Powerful Agent!

## Prompting Tips
"Think step by step"
"Show your reasoning"
"Critique and improve"
