# Day 8 — Agent Anatomy + Memory Types

## Agent = 4 Parts
1. Brain (LLM)  → Thinking
2. Memory       → Remember
3. Tools        → Actions
4. Planning     → Goal → Steps

## Memory Types
| Type | Storage | Duration | Example |
|------|---------|----------|---------|
| Short-term | RAM | Session only | Chat history |
| Long-term | Database/File | Forever | User preferences |
| Episodic | Logs | Past experiences | Previous tasks |
| Semantic | LLM weights | Permanent | General knowledge |

## Autonomy Levels
L1 → Human everything
L2 → AI suggests
L3 → AI acts, human reviews  
L4 → AI independent
L5 → Full autonomy (Future)

## Key Insight
Memory = Agent become smart
No Memory = Chatbot
With Memory = Agent!
