# Day 5 — AI Foundations Notes

## AI Evolution
- 1950s → Symbolic AI (Rules based)
- 1980s → Machine Learning (Data based)
- 2010s → Deep Learning (Neural Networks)
- 2020s → LLMs (GPT, Claude, Gemini)
- Now   → Agents (Autonomous AI)

| Actions | No | Limited | Yes |
