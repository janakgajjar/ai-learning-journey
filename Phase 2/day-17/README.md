# 📄 PDF RAG Chatbot

## What it does
Upload any PDF and ask questions.
AI answers from the document content!

## Tech Stack
-  LangChain
-  Google Gemini API
-  FAISS Vector DB
-  Streamlit

## How to use
1. Upload a PDF
2. Ask questions
3. Get AI-powered answers!
